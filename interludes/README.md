# Future Interludes

The full campaign requires 999 separate, math-supported Interlude games, one between each consecutive pair of the 1,000 Towers.

**Current implementation scope: Tower 1 only.** No Interlude is implemented or registered in the playable catalog. Campus Sprint has a design script, but its implementation is deferred under the user's latest scope instruction. Do not create additional adventures or placeholder gameplay until requested.

Future authored modules belong here, named `interlude-0001.js` through `interlude-0999.js`. The shared campaign sequencing functions already reserve those IDs without presenting them as playable.
