# Runtime art and lighting

These assets are bundled locally with the game; playing makes no third-party requests.

- **Civilian explorer, researcher and Mara Voss, including native idle/walk/run motion:** Microsoft Rocketbox Avatar Library, MIT, copyright © 2020 Microsoft. Source: https://github.com/microsoft/Microsoft-Rocketbox/tree/0943055db6ec570bcef9f2c8b41c9e5467c808f9 . Characters `Male_Adult_02`, `Male_Adult_03`, and `Female_Adult_01`; male motions `m_idle_neutral_01`, `m_walk_neutral`, `m_run_neutral`, and their `f_` counterparts for Mara. Local files: `explorer.glb`, `researcher.glb`, and `mara.glb`. The complete license is in [ROCKETBOX-LICENSE.txt](ROCKETBOX-LICENSE.txt). Adaptations: PBR material reconstruction, 1,024-pixel texture limits, common physical scale and forward axis, and native motion retargeted into each character's rest pose with horizontal root travel removed. Rebuild with `blender -b --python tools/build-human-assets.py -- /path/to/Microsoft-Rocketbox assets/realism`. The previous helmeted Mixamo character has been removed from the runtime.
- **Compatibility file for cached earlier releases:** `operative.glb` remains available for previously cached scripts only. It is Mixamo’s Vanguard character from the [Three.js r170 Soldier example](https://github.com/mrdoob/three.js/blob/r170/examples/models/gltf/Soldier.glb), under [Adobe’s Mixamo usage terms](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html). The current game loads the three civilian models above plus the android and helicopter below.
- **HDR lighting probe:** `royal_esplanade_1k.hdr`, originating from HDRI Haven / Poly Haven's CC0 lighting collection, mirrored in the Three.js r170 examples. Source: https://github.com/mrdoob/three.js/blob/r170/examples/textures/equirectangular/royal_esplanade_1k.hdr . Local filename: `institute-light.hdr`.
- **Campus night background:** original generated environmental image created for Math Tower, stored as `campus-night.png`. It is a distant backdrop, not filmed footage.
- **Security android:** original articulated ceramic/metal geometry in `android.glb`, authored by `tools/build-android.py`, using the MIT Rocketbox skeleton and Idle/Walk/Run motions credited above. No human texture or skin is used for hostile androids. The martial-arts poses are original runtime animation; no claim of authentic instructional technique.
- **Helicopter:** Heiko Schulz’s Eurocopter EC135 model for FlightGear, copyright © Heiko Schulz and contributors, GPL-2.0. Upstream: https://github.com/FGMEMBERS/ec135/tree/6c649b38108170cf91bc2ed14c20606a0640fa42 . `helicopter.glb` combines the exterior, cabin, flight deck and rotor models with local textures. Adaptations: selected a single skid/configuration, converted AC3D surfaces/UVs to glTF, rebuilt glass/PBR materials, aligned the ground and rotor pivot, and added the separately credited Rocketbox pilot at runtime. Corresponding source for all included model parts/textures is bundled in [source/ec135-source.tar.gz](source/ec135-source.tar.gz); conversion code is [tools/build-helicopter.py](../../tools/build-helicopter.py). The model and derived asset remain GPL-2.0; see [EC135-LICENSE.txt](EC135-LICENSE.txt) and the upstream README in the archive for full credits. Build: `blender -b --python tools/build-helicopter.py -- /path/to/extracted/ec135`. No FlightGear flight-control code or audio is used.
- **Environment, machinery, friendly robots and weather:** original procedural geometry authored for Math Tower. Concrete and brushed-metal surface maps are generated locally by the renderer. The human rig is a production asset; the environments remain authored procedural sets, not scanned real buildings.
- **Three.js and add-ons:** r170, MIT. License: `../../vendor/THREE-LICENSE.txt`.

The game uses its own institute, characters and story. The television reference informed atmosphere and pacing; no television footage, music, likenesses or franchise assets are included.
